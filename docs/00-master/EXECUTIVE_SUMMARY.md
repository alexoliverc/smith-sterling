# Resumo Executivo

Smith Sterling possui uma plataforma de crédito digital em desenvolvimento. Em `main` no commit `39129c3` há código, esquema de dados e testes para fluxo público e administrativo de crédito.

O repositório contém mecanismos que bloqueiam a entrada em produção quando dados institucionais ou autorização regulatória ainda forem provisórios. Logo, o código não deve ser apresentado como instituição autorizada ou plataforma pronta para produção.

A continuidade entre agentes é governada por Git, este conjunto documental, ADRs, roadmap recuperado e registros de sessão.
